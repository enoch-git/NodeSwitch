# NodeSwitch

Designing a mains-powered smart extension platform with independently timed output ports, local push-button control, LED time
indication, and hardware-focused protection for domestic AC loads. The PCB separates high-voltage switching from low-voltage
control and incorporates input protection, relay-driving, suppression, and safe current-routing practices.
Technologies: 230 V AC PCB Design, Fuse Protection, MOV (S14K275), Common-Mode Choke, Relay Switching,
TBD62003APG Driver, RC Snubbers, Creepage/Clearance, KiCad, Embedded Control.
